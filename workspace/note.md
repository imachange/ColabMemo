# Go化判定チェックリスト（Yes/No）

Yes が多いほど Go 化の価値が高いです。

1. スクリプトが長大化（目安 200 行超）して読みにくい
2. 条件分岐・例外系が増えて保守がつらい
3. 複数人で継続的にメンテする予定がある
4. 仕様変更が頻繁で、テスト自動化を強化したい
5. 失敗時の原因追跡（ログ・エラーハンドリング）を改善したい
6. 並列処理やパフォーマンス改善の要件がある
7. 実行環境が複数 OS（Linux/macOS/Windows）にまたがる
8. bash/awk/sed など環境依存で不具合が起きたことがある
9. 配布先で依存コマンドの差異を減らしたい（単一バイナリ化したい）
10. CI/CD や本番運用で「壊れると困る」重要処理である

## 判定の目安
- Yes 0〜3: シェル継続で十分
- Yes 4〜6: 一部を段階的に Go 化検討
- Yes 7 以上: Go 化を強く推奨
